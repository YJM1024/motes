# Motes Lite 项目说明

Motes Lite 是一个面向游客共享空间的轻量网页应用工作台。它沿用 Motes 现有项目、版本与数据接口，把日常路径聚焦在创建或选择应用、描述需求、预览、迭代、恢复和发布。新应用默认采用固定 React 19 + Tailwind CSS 4 工程；既有单文件 HTML 应用保持原有流程。

## 三分钟体验

1. 打开[线上 Lite](https://motes-yangjunmin.yjm1024.chatgpt.site/)并选择或新建应用。
2. 发送一个页面需求。模型可用时，服务端先生成简短计划，再生成应用；没有模型配置时可使用标注明确的本地示例。
3. 在隔离预览里操作页面，再用自然语言提出一项修改。
4. 查看源码面板中的工程文件（面板只读），打开版本历史对比或恢复代码版本。
5. 发布所选版本，或导出单文件 HTML。

## 当前功能

- 游客可进入共享空间，选择项目与应用并创建新应用；共享空间中项目、应用、对话和 SDK 业务数据由所有访客共享。
- 新 React 应用采用固定 scaffold。模型新建时生成 `src/App.jsx` 与 `src/index.css`；后续模型修改仅针对这两个文件。源码面板可查看 7 个工程文件，但不支持手工编辑。
- React 预览、分享、发布和 HTML 导出会编译 React runtime 与 Tailwind CSS。构建只处理可信依赖，不执行生成源码；应用在隔离 iframe 中运行。旧 HTML 应用继续使用原来的完整 HTML 生成与补丁修改路径。
- 可查看版本历史、比较版本、恢复代码版本并发布固定版本链接。恢复代码版本只切换代码，不回滚应用通过 Motes SDK 显式保存的业务数据。
- 工作台预览和公开页面中的 Motes SDK 桥将显式保存的 JSON 键值关联到该应用的共享业务数据。导出的独立 HTML 没有宿主 SDK 桥，SDK 数据仅临时有效，界面会提示不会写回。
- 移动界面可在聊天和预览间切换。Lite 依赖网络；完整离线工作台仍在[完整版](https://github.com/YJM1024/motes/tree/full-product)。

## 实现取舍

- **默认 React/Tailwind，兼容旧 HTML。** 固定 scaffold 提供结构清楚的两文件修改面，Tailwind 使用静态完整类名在服务端编译。旧 HTML 应用保留已有的预览、编辑和单文件导出行为。
- **固定工程而非通用构建平台。** 固定入口与依赖由工作台维护，避免安装用户生成的包或运行任意构建脚本；代价是不支持任意 npm 依赖、容器与任意多文件工程。
- **游客共享而非账号体系。** 无需注册即可使用，但项目和应用业务数据对所有访客共享，不具备个人私有空间、账号找回或访问控制。
- **代码版本与业务数据分层。** 历史版本恢复只改变当前代码指针；SDK 的业务数据独立保存，因此恢复代码不会撤销业务数据写入。
- **共享 SDK 与独立导出边界清楚。** 工作台预览和公开页面由宿主提供 SDK 桥；独立 HTML 导出脱离宿主，只能临时运行并显示不持久化状态。
- **模型计划和执行分两次调用。** 当前模型模式先生成简短计划，再生成或修改应用；界面显示阶段状态，不展示隐藏推理或代码流。demo 模式采用本地预设，不调用模型。

## 完成范围与当前不做

已实现：固定 React scaffold、旧 HTML 兼容、隔离预览、只读源码查看、应用创建与修改、代码版本历史及恢复、版本对比、公开发布、单文件 HTML 导出、共享 SDK 业务数据桥。

当前不包含：账号认证/auth、代码流式输出、ZIP 项目包、容器或任意依赖安装、任意多文件源码与离线工作台。检查流程只验证结构、JSX/模块导入约束及 Tailwind 编译等静态条件；不能据此推断应用功能已通过浏览器测试。

## 后续优先级

1. 继续核对 Lite 常用路径在公开环境中的行为和兼容性，优先处理影响创建、预览、恢复或发布的明确问题。
2. 改善固定 React 工程与旧 HTML 工程的提示和错误信息，让用户容易理解哪些改动可做、数据会保存到哪里。
3. 根据实际使用反馈维护本地启动、迁移和发布说明；只有产品范围明确变化时，再评估认证、多文件工程或其他扩展。
