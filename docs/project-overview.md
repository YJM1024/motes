# Motes Lite 项目说明

**作者：杨俊敏**

Motes Lite 通过自然语言创建小型网页应用。用户描述需求后，可以操作生成的页面，继续提出修改，比较和恢复代码版本，最后通过公开链接或独立 HTML 交付应用。

[在线体验](https://motes-yangjunmin.yjm1024.chatgpt.site/) · [代码仓库](https://github.com/YJM1024/motes)

## 产品流程

1. 进入游客公共空间，选择项目或新建应用。
2. 发送需求，工作台展示规划、执行、检查、保存四阶段。
3. 在预览中操作页面，确认交互和数据行为。
4. 通过对话修改，查看源码、比较版本或恢复代码。
5. 发布选定版本，或下载独立 HTML。

## 实现思路

宿主工作台负责项目、对话、版本和发布。生成应用采用固定 React 19 + Tailwind CSS 4 工程，模型专注于两个应用源码文件。工作台解析并编译源码，在隔离 iframe 中运行应用；已有 HTML 应用沿用原有流程。

D1 保存工作台数据和完整代码快照。生成请求具有独立编号、内容指纹和处理状态，配合应用锁与事务提交，处理重复发送、并发修改和保存重试。应用通过受控 Motes SDK 显式保存共享业务数据。

## 关键取舍

| 选择 | 设计考虑 |
| --- | --- |
| 固定工程与两文件修改范围 | 聚焦小型网页应用，让生成、编译、预览和导出保持一致。 |
| 计划与执行两次模型调用 | 先整理需求和修改步骤，再生成源码或局部补丁。 |
| 精确补丁与完整快照 | 修改位置可校验，历史成果可比较和恢复。 |
| 游客公共空间 | 无需注册，评审可直接操作，使用共享演示数据。 |
| 代码与业务数据分开保存 | 恢复代码版本时保留已保存的业务数据。 |
| 托管发布与 HTML 导出并存 | 托管页提供 SDK 桥，独立文件携带运行时和样式。 |

## 完成范围与后续方向

已实现自然语言生成与连续修改、React 与既有 HTML 预览、项目组织、源码查看、版本比较与恢复、共享业务数据 SDK、公开发布、单文件 HTML 导出及小屏切换。

本版本聚焦固定依赖的前端应用，源码面板用于查看。当前未包含个人账号、代码流式输出、通用多文件工程和 ZIP 工程包。后续优先完善数据初始化、保存反馈和连续修改体验，其次加强错误定位与恢复，再扩展工程能力。
