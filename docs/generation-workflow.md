# 生成、预览与版本流程

## 创建与连续修改

新应用采用固定 React 19 + Tailwind CSS 4 工程。模型创建 `src/App.jsx` 与 `src/index.css`，入口与依赖由工作台维护。后续使用精确文件补丁，原文件唯一匹配并整批校验后统一应用。

真实模型模式依次生成简短计划与应用源码或修改补丁。界面展示规划、执行、检查、保存四阶段。示例模式使用本地预设应用；已有 HTML 应用保留对应流程。

## 编译与预览

保存前解析 JSX 与模块导入，编译静态 Tailwind 类名。构建阶段不执行生成的应用代码。代码版本保存后，在隔离 iframe 内运行应用。

源码面板可查看七个工程文件。用户可在预览中检查表单、按钮、计算和数据保存等行为。

## 版本与业务数据

每次保存留下完整代码快照，支持历史预览、实际增删行比较和代码恢复。查看历史不会改变当前保存版本；恢复操作切换当前代码。

业务数据通过 SDK 独立保存，代码恢复时保持当前业务数据。普通输入由应用显式调用 SDK 后持久保留。

## 请求恢复

客户端记录原请求编号、需求和目标上下文，刷新后可核对原请求结果。已经暂存的生成结果支持仅重试保存，复用原模型结果。

“停止本页等待”中止浏览器等待；之后核对原请求状态，再决定后续操作。

## 发布与导出

发布将选定代码版本托管为公开链接。React 应用的预览、发布与导出共用编译路径，运行时和样式内嵌。托管页提供共享 SDK 数据桥；独立 HTML 可单独打开，SDK 数据作为临时状态使用。
