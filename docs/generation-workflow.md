# 生成、预览与版本工作流

新应用默认采用固定 React 19 + Tailwind CSS 4 工程；已存在的单文件 HTML 应用继续使用原有 HTML 创建、修改和导出路径。当前模型模式通常分两次上游调用：先生成简短计划，再生成或修改应用。demo 模式使用本地示例，不调用模型。界面展示阶段状态，不流式输出代码。

## React 创建与修改

创建 React 应用时，模型只生成 `src/App.jsx` 与 `src/index.css`；固定入口、依赖及其他 scaffold 文件由工作台提供。后续修改以严格文件补丁提交，只能变更这两个源码文件。补丁搜索片段必须在原文件中唯一匹配，修改按原文件整体校验后应用。

源码面板只读，可查看 7 个工程文件。它用于检查当前工程内容，不是可手工编辑的源码编辑器。固定工程不支持任意 npm 依赖、容器、任意多文件源码或 ZIP 工程包。

## 静态检查与隔离预览

保存前，React 工程会解析 JSX 与模块导入，并使用静态源码中的 Tailwind 完整类名编译 CSS；导入仅允许 React，CSS 外部导入与 URL 不受支持。这些检查发现结构或约束问题，不代表页面功能已经过浏览器功能测试。

工作台构建预览 runtime 时，只打包已安装的可信 React 依赖，不执行模型生成的 App 源码。生成应用在带脚本与表单权限、无同源权限的隔离 iframe 中运行。旧 HTML 路径也使用隔离预览；其结构检查不等于已执行脚本的功能测试。

## 版本、恢复与数据

检查通过后，结果保存为新的应用代码版本；失败时保留当前保存版本。版本历史支持查看和恢复代码，版本对比可比较两个已保存版本。React 版本可选源码文件查看差异，旧 HTML 版本比较 HTML 文本。版本恢复只改变当前代码版本指针，不回滚应用通过 SDK 显式写入的业务数据。

工作台预览和公开页面可提供 Motes SDK 桥。应用明确调用 SDK 保存的键值会进入该应用的共享业务数据，所有访客共享这些数据。未通过 SDK 保存的普通输入、DOM 状态不会自动持久化。

## 发布与独立 HTML 导出

React 的预览、公开页面、分享和 HTML 导出使用内嵌 React runtime 与实际编译的 Tailwind CSS，不依赖 CDN。公开页面由宿主提供 SDK 桥；导出的独立 HTML 没有宿主桥，SDK 数据仅临时有效，并会提示不会写回工作台。旧 HTML 应用继续沿用其既有 HTML 导出内容。
