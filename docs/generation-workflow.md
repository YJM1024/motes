# Motes Lite 生成工作流

Lite 的生成请求通过四个阶段展示进度：**规划 → 执行 → 检查 → 保存**。进度只说明当前阶段，不会展示隐藏推理或生成中的代码流。

## 四个阶段

1. **规划**：模型模式会先生成简短任务清单，作为后续执行的参考。demo 模式使用本地预设计划与模板，不会伪装成 AI 规划，也不会调用模型。
2. **执行**：新建应用时生成完整的单文件 HTML。修改已有应用时，模型返回严格格式的局部替换补丁；补丁必须唯一匹配原代码、互不重叠，并满足大小限制，之后才会整体应用。
3. **检查**：对候选 HTML 做有限的结构检查。此步骤不会运行生成的 JavaScript，也不代表已通过浏览器功能测试。
4. **保存**：检查通过后才创建并保存新版本。任何规划、执行或检查失败都会保留原保存版本，不会将失败结果写成版本。

模型模式通常需要两次上游模型调用：一次生成简短计划，一次执行生成或修改；两个阶段的 token 用量汇总记录，额度仍按用户请求计数。demo 模式在本地选择预设计划和模板，不进行模型调用。页面显示阶段状态，不提供代码流式输出。

## 版本对比与业务数据

预览区工具栏中的“版本对比”可比较两个已保存版本，查看逐行新增、删除与未变代码。超出受限对比预算时会明确提示无法展示，不会以估算内容代替实际差异。

版本还原和版本对比针对保存的 HTML。应用经 Motes SDK 明确写入的业务数据保存在独立数据层，不会随代码版本还原而回滚。普通表单输入、页面 DOM 状态和计时器不会自动持久化。

## Lite 范围

Lite 不提供代码流式输出、登录流程或 ZIP 打包导出。生成的 HTML 是单文件内容；界面能力及服务端配置仍以当前部署为准。
