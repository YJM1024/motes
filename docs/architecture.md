# 架构与工程取舍

## 请求链路

```text
React 工作台
  ├─ 项目、版本与生成 API → Cloudflare Worker → D1
  ├─ 服务端模型适配 → OpenAI Responses API
  └─ 完整 HTML → 受限 iframe 预览 / HTML 导出
```

`app/page.tsx` 管理工作台交互与预览；`app/api` 暴露会话、项目、生成和还原接口；`lib/forma` 包含示例引擎、模型适配、归属校验与持久化逻辑；`db/schema.ts` 和 `drizzle` 定义数据结构及迁移。历史命名 `forma` 保留以兼容已有数据。

管理页位于 `app/manage`，通过 `/api/workspace` 和 `lib/motes/management.ts` 访问组织层。精确契约在 `lib/motes/types.ts`，接口与过滤语义见[工作空间管理基础](workspace-api.md)。管理基础首次部署于 v6，本地联合验收和线上管理 API Smoke 均通过；具体边界见验收说明。

后续源码由 `lib/motes` 组织设置、分享、备份、模板、候选、讨论、诊断和用量，客户端恢复位于 `app/hooks`。讨论使用独立文字线程；生成、候选和讨论共享模型预算，手工编辑不调用模型。增量的实际上线状态见[验收状态](acceptance.md#当前验收状态)。

## 为什么以完整 HTML 为版本单位

每次生成返回包含内联 CSS 和 JavaScript 的完整 HTML。这样能直接预览、导出和还原，避免引入项目依赖安装与构建执行。代价是每次修改要提交完整当前代码，代码较大时成本增加；当前不支持多文件工程、后端服务或依赖安装。模型可能产生逻辑错误，完整性检查不等于功能正确。

示例引擎只接受约定的三个应用和有限修改，不以静态结果冒充通用模型生成。服务端同时具备 Key 与模型 ID 时才开启模型模式。

## 持久化与一致性

匿名会话使用随机 Cookie。旧隔离模式下，服务端以 Cookie 摘要作为项目归属；共享模式下，服务端将业务归属映射至固定公共演示空间，Cookie 仍用于访客级限额追踪，但不隔离该空间的业务数据。数据库保存项目、完整版本、请求状态及生成锁。读取、修改与还原都检查实际空间归属；修改请求还检查来源。

每条生成请求带独立编号与内容指纹。相同请求重试会复用已完成结果，冲突内容会拒绝；项目生成锁防止并发修改。版本与项目指针通过 D1 批量事务写入，生成失败不覆盖已有代码。还原只改变当前版本指针，历史继续保留。

选择匿名身份降低体验门槛，也不提供账号找回或跨设备身份恢复。旧隔离模式下，Cookie 丢失后无法恢复原访客空间。预览中的一般 DOM 输入不会自动写入项目或版本；共享模式 SDK 可将应用显式保存的键值记录写入独立运行数据表，区分代码版本和应用数据。

管理增量将原 `forma_projects` 明确视为应用，保留其 ID、owner、全部版本和当前指针。新增 `motes_*` 表组织独立测试资料、默认工作空间、项目分组、应用元数据与标签。迁移仅创建结构；首次管理请求按当前访客幂等补建元数据。新应用可明确指定项目并在生成事务中直接归组；未指定目标的旧接口继续归默认项目。应用改名在同一事务同步旧标题，原工作台和生成/还原接口继续兼容。

管理写入校验本站来源和空间归属。旧隔离模式拒绝跨访客引用；共享模式中所有访客共同查看和修改公共演示空间，但仍受服务端空间归属、Origin 与具体操作检查。归档和恢复仅改变组织元数据，项目归档不删除其中应用；移除标签只解除标记。数量限制在插入 SQL 中执行，复合管理写入使用原子批处理。公共演示空间不是个人账号或团队系统，也不提供永久删除应用。

共享运行数据由工作台在 sandbox iframe 与可信父页之间转发的消息桥接承载。子页通过 `window.motes.data` 显式 `get`/`set`；SDK 只传 JSON 键值，父页再使用当前应用 ID 和服务端归属检查调用 API。冲突使用 revision CAS 拒绝旧值覆盖。该机制不把任意 DOM、表单、未发送内容或计时器状态自动持久化；接口启用、容量和备份规则见[共享运行数据](shared-runtime.md)。

## 执行与秘密边界

服务端持有模型 Key，浏览器只向本站接口提交需求。模型请求设置超时和输出长度上限，拒绝截断或不完整 HTML；日志仅记录状态和耗时，不记录需求内容及密钥。需求及当前代码仍需发送到模型服务，应避免在需求中填写敏感信息。

生成代码在不具有同源权限的 `sandbox="allow-scripts allow-forms"` iframe 中执行；预览注入 CSP 限制外部资源和网络，并移除自动跳转元标签。源码以文本展示，导出则提供原始 HTML。该隔离边界适用于工作台内预览，导出后独立打开由使用者所在浏览器执行。

当前采用请求长度、每日额度、版本上限与项目锁控制资源消耗。匿名额度无法提供严格的个人身份约束，尚未完成公开生产环境的负载、滥用与长期运行验证。

## 部署边界

本地与生产使用独立 D1 数据库及环境变量。Sites 负责构建、版本和部署；部署前配置运行时秘密变量，部署后逐项检查模型调用和数据恢复。生产 v14 已通过既有 UI 复核；本轮共享运行数据 SDK、备份导出选项与历史计数器适配尚未部署或对生产数据执行导入。本轮已知范围及验收状态见[验收说明](acceptance.md)。
