# 离线工作台

离线能力用于同一浏览器里的公共演示空间。它依赖浏览器本地 IndexedDB 保存已缓存的工作空间资料、离线源码版本和 SDK 业务数据；不等同于云端备份，也不会自动执行或补发模型请求。

## 开始前

首次使用时保持联网，并在工作台打开目标应用，等应用、版本和预览加载完成，以及“正在准备离线模式”提示结束。工作台会缓存页面所需资源、当前公共演示空间的会话、设置、应用列表和已打开应用资料。完成缓存后，可在断网时刷新或重新打开主工作台。只有已经缓存的内容可供断网查看；其他设备、清除站点数据后的浏览器、从未打开过的应用都不能从本地恢复。浏览器清理本地存储后，需要重新联网准备；本地缓存不能替代服务端保存和导出备份。

## 断网时可以做什么

- 查看已缓存应用并继续在隔离预览中运行。运行页面自身的普通输入、DOM 状态和计时器仍按应用逻辑处理；它们不会因此自动保存。
- 在已缓存应用上保存手工源码版本或从历史版本建立本地还原分支。保存成功后会显示为本设备上的待同步更改，不会覆盖公共空间里的版本。
- 创建受限的本地示例：旅行预算、任务看板、番茄钟或空白应用。示例修改仅支持内置模板明确提供的主题、颜色和预算调整；不支持自由需求生成。
- 页面明确调用 `window.motes.data` SDK 写入的业务值会存入本地待同步队列。单个值最多 12 KiB；每个应用最多 64 个键、合计 256 KiB。未使用 SDK 保存的数据仍是临时状态。

离线创建的应用会作为本地独立副本保留。同步成功时，它会以新应用 ID 导入公共空间，不会替换已有应用。

## 恢复联网与冲突

网络恢复后，离线状态会重新核对，但不会自动同步。请在工作台点击“手动同步”。同步先重新验证会话和公共空间身份，再按原请求编号处理本地队列；不会调用 AI。页面关闭、刷新或网络恢复本身都不会触发模型重放。

如果服务端的应用基准版本或 SDK 数据 revision 已变化，系统会保留本地分支并标记冲突，不会静默覆盖公共数据。打开“本地更改”可查看条目，导出源码 HTML 或业务数据 JSON；“放弃此更改”只将本地条目移出同步队列，不会删除云端数据。处理冲突前请先导出需要保留的本地内容。

## 当前边界

- 离线模式不是本地 AI；真实模型生成、讨论和模型候选不会排队，也不会在联网后自动补发。
- 新设备、未缓存的应用及未缓存的页面资料仍需网络读取。若浏览器存储不可用或空间已满，本地保存会失败并提示，不应视为已保存。
- 项目管理、分享、稳定发布、候选赛马等高级工作台操作需要网络。
- 离线缓存不包含服务端 API Key、Cookie 或登录凭据。SDK 离线记录只限应用显式写入的值；不缓存任意预览 DOM。
- 该离线实现面向共享公共演示空间。正式账号、跨设备私有同步和团队隔离不属于此功能。

自动化边界测试见 `tests/offline-engine.test.mjs`、`tests/offline-sync-status.test.mjs`、`tests/offline-changes-panel.test.mjs` 和 `tests/offline-workspace-controls.test.mjs`。源码能力是否已进入线上版本，以[验收记录](acceptance.md)为准。
