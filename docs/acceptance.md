## 真实模型结果与限制

- **2048 游戏**：首版可玩，键盘与方向按钮操作使分数达到 16；但 SDK 持久化失败，保存状态停留在“正在保存”，读回最高分仍为 4、revision 1。第二版的重启按钮变蓝，v2→v1→v2 恢复操作通过观察；此补丁没有修复首版保存缺陷，游戏持久化仍记为失败。v33 的提示约束调整不会追溯修复已经保存的应用版本。
- **任务清单**：首版把 SDK 初始空值 `null` 当成无效数据，首次初始化失败。第二版修复后，在观察范围内新增、完成、删除任务以及刷新恢复均通过；刷新后保留 1 条已完成任务，SDK revision 4。
- **小费计算器**：新建及功能补丁在观察范围内通过。输入账单 120、小费比例 10%、3 人，得到小费 12、总额 132、人均 44；补丁后输入仍保留，共享数据保存、刷新读取和公开页面读取均观察通过，SDK revision 1。

模型请求完成或版本成功保存不等于应用功能通过。首轮游戏持久化与任务初始化失败保持为失败记录；第二轮只记录实际观察到的操作范围，不外推至未测试功能。公开证据：[精简验收摘要](verification/v33-final-evidence.json)、[真实模型请求、差异与用量明细](verification/v33-real-model-check.json)、[CI job 记录](verification/v33-ci-check.json)、[生产清理摘要](verification/v33-production-cleanup.json)。

## 产品与数据边界

生成流程展示规划、执行、检查、保存四阶段；真实模型模式通常先规划、再执行，共两次上游调用。新 React 工程使用固定 React 19 与 Tailwind CSS 4 scaffold，模型只可修改 `src/App.jsx` 和 `src/index.css`，源码面板只读。已存在的单文件 HTML 应用继续使用原 HTML 工作流。编译阶段不执行生成的 App，预览在隔离 iframe 中运行。版本比较与恢复只作用于代码，恢复不会回滚 SDK 业务数据。公开链接托管指定版本；独立 HTML 导出没有宿主 SDK 桥，SDK 数据只临时有效。

Lite 面向共享游客空间，访客可见且可修改其中内容；不存放个人或机密数据。当前不提供账号认证、代码流式输出、ZIP 项目包、容器或任意依赖安装、任意多文件工程及离线工作台。静态检查不能替代应用功能测试；上述模型案例仅代表记录的交互观察范围。
