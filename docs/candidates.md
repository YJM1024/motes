# 多方案创作：大预览、分段切换与逐轮独立方案

v21 将多路创作放入普通对话与大预览工作台。发送需求后继续使用常规聊天；聊天区域只显示每轮任务摘要，候选完整网页共用大预览区中的唯一 iframe。A/B/C/D 分段条放在现有“实时预览”工具栏右侧。切换候选只替换预览内容，不在聊天里重复渲染多张预览卡。独立 `/compare` 仍保留高级并排比较入口，主操作留在工作台。

## 每轮方案与采用

每轮的候选数量是该轮自己的配置。更改后续一轮的数量不改变当前组的 A/B/C/D tabs 或候选。采用某一候选后，可基于当前应用版本发起新一轮，并另选 2/3/4 路及相应预算。刷新后读取已保存的各轮结果，按原请求 ID 恢复，不会重发生成请求。

付费赛马须勾选对应调用确认；示例模式不调用模型。当前每日次数限额关闭时不展示访客、共享空间和全站剩余次数/低额提示，但真实用量、幂等、并发锁、CAS/版本校验及服务方额度仍生效。离线时 2/3/4 路不可用并提示联网，单次示例保留。

## 预览和数据边界

主工作台只保留一个完整应用预览 iframe。候选切换在该 iframe 中显示所选 HTML；用户正在编辑或预览的其他候选不会因调整下一轮路数而覆盖。采用需要用户明确选择，创建的代码版本仍按既有冲突与基准检查处理。公共空间内的应用和数据对访客可见、可修改，不是私有应用。

旧 `/compare` 页仍支持独立的高级并排比较，但不是主赛马操作路径。
