# 多方案创作：原位赛马、比较与采用

当前 v20 主创作区支持单次生成和 2/3/4 路方案。用户在输入框上方选择数量，通过主发送按钮或 Ctrl+Enter 发起；所有候选在当前工作区的主界面同台显示，可查看进度、比较、重试失败单路、暂存/保存或采用。刷新后会按原请求 ID 读取已生成结果；停止等待只停止当前页面等待，不代表服务端任务或费用已取消。旧独立 `/compare` 页面仍可用，但主流程无需跳转。

## 调用确认与限制

付费赛马须在数量选择旁明确勾选对应模型调用确认；未确认时不发起请求。当前公共演示环境关闭每日访客/公共空间/全站次数限额。此时不展示三层剩余次数或低额提醒，但真实用量记录、请求幂等、并发锁、CAS/版本校验，以及模型服务方余额、限流和超时仍有效。无网络时 2/3/4 选项禁用并提示联网，单次离线示例仍可用。

多路方案使用同一所选模型与不同策略，不自动评分或自动择优。每路候选独立保存；失败路可由用户确认后重试，已有成功结果不受影响。选择暂存/保存不会重复调用模型；采用只将已生成内容应用到当前应用或创建新应用，不产生新模型调用。所有应用、项目和已保存数据处于公共共享空间，访客均可查看和修改。

## API 与恢复

前端创建载荷通过 `/api/candidates`，指定 `count: 2|3|4` 及匹配的 `confirmCalls`；兼容旧两路请求字段。失败单路使用候选 retry 接口和新请求编号，并带 `confirmOneCall: true`；采用调用 `/api/candidates/:id/adopt`。刷新读取组详情，不以新 ID 重发旧任务。服务端继续校验 Origin、请求身份、版本基准、生成锁、目标项目及容量。

## 验收边界

当前全量 358 项自动测试、TypeScript 与构建通过。本轮 0 次真实模型调用。真实 SQLite/mock 覆盖候选、幂等、并发、保存、采用和冲突保护；真实浏览器曾验证主界面 2/3/4 路、Ctrl+Enter、输入草稿刷新恢复、编辑冲突保护和390px布局。线上生产 v19 完成 4 路示例生成、并排查看及切换候选；v20 刷新后恢复 4/4 并切换候选仍在主路径成功。付费 AI 确认未勾选时无调用。仅保留一组 demo 候选，未创建新应用或改动用户原作。生产核验仅覆盖四路 demo 的生成、比较和刷新读回；采用及后续版本检查在本地完成。v19 生产证据与 v20 的额度提示/焦点样式修复分开记录，不据此声称三/四路真实模型生成质量已逐路评估。手机流量和无痕 UI 仍待用户人工验收。
