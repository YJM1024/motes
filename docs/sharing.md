# 固定版本分享与撤销

在版本工具中选择版本，展开“分享所选版本”。创建前会明确提示：链接公开所选版本的标题、可交互页面及完整 HTML 源码，任何持有链接的人均可查看。确认内容适合公开后，点击“公开版本并创建链接”；读取列表、比较版本和切换版本不会自动公开。

链接保存明确的版本编号和创建时的标题。之后生成新版本、切换或还原历史、重命名应用，都不会改变已分享内容。分享列表可以复制、查看或撤销链接。撤销会立即阻止后续页面及接口读取；已经打开、复制或下载的内容无法收回。再次公开需要明确创建新链接，重试旧请求不会恢复已撤销链接。

固定版本分享始终指向创建时选定的快照。稳定发布是不同能力：发布者可明确将同一个发布链接更新为另一已保存版本，也可暂停并使访问返回 404，之后重新启用仍恢复同一链接。v9 稳定发布增量尚待发布；不要用固定分享的撤销/新建流程代替，也不要认为固定分享会随发布更新漂移。

公开页面是只读分享页，不是工作台；匿名访问者只能操作该版本的隔离预览和查看源码，不能编辑原应用。预览输入是临时状态，不保存回原应用。页面和公开接口不会返回访客资料、所有者标识、需求、对话、其他版本或模型配置。HTML 本身可能包含创作者写入的信息，公开前必须自行核对。

## 接口

所有者接口依赖原匿名访客 Cookie。写入还需本站 Origin；不接受客户端提交 HTML、标题、所有者或 Token。

| 操作 | 接口 | 内容 |
| --- | --- | --- |
| 查看本应用分享 | `GET /api/projects/:id/shares` | 仅所有者可读，返回链接状态与固定版本，不返回源码或对话 |
| 创建 | `POST /api/projects/:id/shares` | `{versionId, requestId}`，请求编号为 UUID；成功返回 `201 {share}`，同一请求重试返回同一记录 |
| 撤销 | `DELETE /api/projects/:id/shares/:shareId` | 仅所有者且需匹配应用；可安全重复撤销 |
| 只读页面 | `GET /share/:token` | 无需 Cookie，固定版本预览及源码；不存在和撤销使用相同友好提示 |
| 最小公开数据 | `GET /api/shares/:token` | 仅 `{title, versionNumber, html}`，不可用时统一 404 |

分享 Token 来自 32 字节安全随机数，以 64 位小写十六进制表示；不复用。Token 是访问此单一版本的凭据，数据库保存它用于所有者再次复制链接，不写入应用日志。请求编号唯一约束避免并发双击重复创建；副作用已完成而响应失败时，客户端沿用原编号核对。每应用最多 20 个有效链接，每访客最多累计 200 条分享记录（包含已撤销记录）。检查在 SQL 原子插入中执行，不依赖界面限制。

## 隔离与迁移

`0003_fixed_version_shares` 仅新建 `motes_shares` 表及索引，不改旧应用、版本、所有权或当前版本指针。必须先执行现有 `0000`、`0001`、`0002`；保留旧迁移和 snapshot 链。

生成的 HTML 始终先作为转义文本放入源码区，再由可信引导代码规范化为 iframe `srcdoc`，不作为分享主页执行。iframe 授予 `allow-scripts allow-forms`，允许 JavaScript 处理表单事件；CSP `form-action 'none'` 阻止真正提交，不授予同源、弹窗或顶层导航能力，使用 no-referrer。预览 CSP 拒绝外部脚本、样式、请求、嵌套框架和自动刷新元标签；分享主页的 `frame-src 'self'` 另外约束 iframe 发起的外部页面导航。分享页面和接口都禁用缓存及搜索索引，撤销不依赖缓存过期。

工作台 `/`（包含源码编辑预览）及 `/manage` 页面同时由 `next.config.ts` 的 HTTP 响应头设置最小 `Content-Security-Policy: frame-src 'self'`，补足仅在 `srcdoc` 内设置 `connect-src 'none'` 无法限制子框架自身导航的边界。此配置经已安装 Vinext 的实际 header matcher/finalizer 验证；不限制主页面脚本、样式和请求，不修改平台认证、API 路径或分享页的独立策略。

本批提供真实 SQLite 测试，覆盖所有者与版本隔离、固定快照、撤销、原子数量限制、请求幂等、响应故障后核对、非法来源、迁移链和转义/隔离标记。分享 GET 路由在没有服务器 DOMParser 的环境返回 200，撤销与不存在统一 404；本地 TCP 受限时测试直接调用同一 HTTP Request/Response handler，并明确报告该限制。上线前仍需真实运行页面及浏览器验证响应头、预览脚本交互、外网导航被拦截、手机布局，以及撤销后重新访问失败。本批未部署或调用真实模型。
