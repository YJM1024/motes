# Motes Lite · 微粒

一个用自然语言创建小型网页应用的 AI 工作台，支持从需求描述、交互预览、对话修改，到版本恢复、公开发布和 HTML 导出。

**作者：杨俊敏** · [在线体验](https://motes-yangjunmin.yjm1024.chatgpt.site/) · [GitHub 源码](https://github.com/YJM1024/motes)

## 快速体验

选择项目并描述需求，例如“做一个可以保存任务的清单”。生成后在预览中添加、勾选任务，再通过对话增加筛选等功能；可查看源码、比较或恢复代码版本，最后发布可运行链接，或下载独立 HTML。

- **真实 AI 模式：** 根据需求生成应用或修改补丁，展示规划、执行、检查和保存进度。
- **示例模式：** 提供旅行预算、任务看板、番茄钟及有限修改，不调用模型。

无需注册。在线 Demo 使用游客公共空间，所有访客共享作品和通过 SDK 保存的业务数据，请使用演示数据。

| --- | --- |

**尚未实现：** 个人账号与用户隔离、代码流式输出、任意依赖安装、通用多文件工程和 ZIP 工程包导出。

**使用边界：** 业务数据须由应用显式通过 SDK 保存，仅向当前保存版及有效的发布／分享版本开放；查看或恢复代码版本不会回滚业务数据。独立导出 HTML 没有托管数据桥，输入仅作临时使用。结构、编译和代表性回归不等于任意需求都被正确实现，复杂需求仍需核验。“停止本页等待”不能保证取消服务端任务或模型费用。

## 实现思路与关键取舍

**技术栈：** React、TypeScript、Tailwind CSS 与 Vinext，部署在 Cloudflare Workers；D1 保存项目、对话、请求、代码版本和应用业务数据。

模型先生成简短计划，再以结构化输出生成源码或精确补丁；工作台完成结构检查与编译后保存版本，在隔离 iframe 中运行。

| 选择 | 原因与代价 |
| --- | --- |
| 固定 React + Tailwind 工程 | 模型只修改应用组件和样式，控制生成、预览与导出的复杂度；暂不开放任意依赖或通用工程构建。 |
| 精确补丁与完整快照 | 修改须唯一匹配且互不重叠，失败时保留原成果；完整快照简化比较与恢复，代价是增加存储。 |
| 请求编号、暂存与事务保存 | 处理重复请求和并发修改；已生成的暂存结果可仅重试保存，减少重复模型调用。 |
| 代码与业务数据分开保存 | 恢复代码保留业务数据；宿主持久化能力统一处理首次空数据、连续写入与冲突，应用仍需保证数据结构兼容。 |
| 游客公共空间与隔离预览 | 降低评审体验门槛，密钥留在服务端；公共空间不提供个人数据隔离。 |

## 继续投入时间的优先级

1. **P0：生成可靠性。** 扩大真实业务断言、连续修改和数据兼容覆盖，优先解决生成后不能正常使用的问题。
2. **P1：错误恢复与交互。** 完善源码定位、补丁／数据冲突提示和请求恢复，让失败原因与下一步操作更清楚。
3. **P2：扩展工程能力。** 在现有流程稳定后支持受控多文件与独立工程导出，再评估个人空间和后台任务。
