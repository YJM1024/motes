# Motes Lite · 微粒

用自然语言创建、修改、预览和交付小型网页应用。

**作者：杨俊敏** · [在线体验](https://motes-yangjunmin.yjm1024.chatgpt.site/) · [GitHub 源码](https://github.com/YJM1024/motes)

## 快速体验

打开工作台，选择项目并描述需求；在预览中操作生成的应用，再通过对话修改、比较或恢复代码版本。完成后可发布选定版本的公开链接，或下载独立 HTML。

无需注册。在线 Demo 使用游客公共空间，作品及通过 SDK 保存的业务数据由访客共享，请使用演示数据。示例模式提供旅行预算、任务看板、番茄钟及有限修改，不调用模型；真实 AI 模式单独标注。

## 实现思路与关键取舍

工作台使用 React、TypeScript 和 Vinext，部署在 Cloudflare Workers；D1 保存项目、对话、请求、代码版本和应用业务数据。真实模型先生成简短计划，再生成应用源码或修改补丁。工作台完成结构检查与编译后保存版本，在隔离 iframe 中运行，并展示捕获到的运行错误。

| 选择 | 原因与代价 |
| --- | --- |
| 固定 React 19 + Tailwind CSS 4 工程 | 模型只修改应用组件和样式，统一预览与导出；暂不支持任意依赖或通用多文件工程。 |
| 精确补丁与完整快照 | 修改须唯一匹配且互不重叠；保存完整版本，便于比较和恢复。补丁不符合要求时保留原成果。 |
| 请求编号、暂存与事务提交 | 处理重复请求和并发修改；已生成的暂存结果可仅重试保存，避免重复调用模型。 |
| 代码与业务数据独立保存 | 恢复代码时保留业务数据；应用须显式调用 SDK，并处理数据结构兼容与写入冲突。 |
| 宿主提供持久化状态能力 | 统一处理空数据、连续保存与冲突，减少模型重复编写异步逻辑；应用仍须提供正确的数据结构和业务行为。 |
| 游客公共空间与隔离预览 | 降低体验门槛，模型密钥留在服务端；公共数据不具备个人空间的隐私边界。 |

## 当前完成程度

**已实现：** 真实模型生成与连续修改、交互预览、项目及应用切换、源码查看、版本比较与恢复、D1 持久化、共享数据 SDK、公开发布、独立 HTML 导出，以及小屏聊天／预览切换。已有 HTML 应用保留原有流程。

**当前边界：**

- 源码面板只读；尚无个人账号、代码流式输出、任意依赖安装、通用多文件工程或 ZIP 工程包。
- 已加入代表性业务的浏览器回归及预览运行错误提示；结构、编译和代表性回归仍不能证明所有自然语言需求都被正确实现，复杂需求需继续核验。
- 普通输入不会自动持久化；应用须通过 SDK 保存。托管页提供数据桥，独立导出 HTML 的 SDK 数据仅作为临时状态。
- “停止本页等待”中止浏览器等待，不能保证取消服务端任务或模型费用。

## 继续投入时间的优先级

1. **P0：生成结果的可靠性。** 扩大真实业务断言与数据兼容覆盖，重点验证复杂需求的生成和连续修改，优先解决生成后不能正常使用的问题。
2. **P1：工程质量与错误恢复。** 完善源码位置、补丁／数据冲突提示及请求恢复体验；持续以 lint、类型检查和自动回归约束迭代质量。
3. **P2：扩大工程能力。** 在现有流程稳定后支持受控多文件与独立工程导出，再评估个人空间和后台任务，避免同时扩大运行、预览和数据管理的复杂度。

## 本地运行与检查

推荐 Node.js 24 与 npm。在仓库根目录依次执行：

```sh
npm ci
node -e "const fs=require('node:fs'); if (!fs.existsSync('.dev.vars')) fs.copyFileSync('.dev.vars.example','.dev.vars',fs.constants.COPYFILE_EXCL)"
npm run build
npm run db:init:local
npm run dev
```

默认地址为 `http://127.0.0.1:5173/`，以终端输出为准。示例无需密钥；真实模型需在本地 `.dev.vars` 中设置 `OPENAI_API_KEY`、`OPENAI_MODEL`，可选 `OPENAI_MODELS` 白名单。该文件已被 Git 忽略。

`db:init:local` 仅用于全新本地 D1；已有库先备份 `.wrangler/state`，再核对并应用未执行的迁移。

```sh
npm test
npm run typecheck
npm run build
npm run verify:http
npm run lint
# 首次执行浏览器业务回归时安装 Chromium
npx playwright install chromium
npm run verify:business
```

CI 在 Ubuntu 与 Windows 上执行 lint（含警告均须清零）、测试、类型检查、构建、全新本地 D1 初始化和示例 HTTP 检查；Ubuntu 另执行浏览器业务回归，覆盖空数据、保存与刷新、代码恢复、冲突、失败反馈、运行错误及预算／计时器操作。这些自动回归不调用付费模型，不能代替真实模型生成效果评估。

主要目录：`app/lite/` 为工作台，`app/api/` 为接口，`lib/forma/` 与 `lib/motes/` 为生成及业务逻辑，`db/`、`drizzle/` 为数据与迁移，`scripts/`、`tests/` 为构建和验证。
