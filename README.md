## 本地运行与验证

使用 Node.js 24（最低 22.13）和 npm。安装依赖并构建后，**新库需按顺序应用 0000–0007 全部迁移**，再启动本地服务；已有库只执行尚未应用的迁移，勿重跑旧迁移。完整命令见[本地启动与迁移](docs/local-setup.md)。

未配置模型也可直接使用示例模式。真实生成需要受保护的服务端 OPENAI_API_KEY 与默认 OPENAI_MODEL；可选 OPENAI_MODELS 管理可选模型白名单。密钥不在界面输入，也不随源码、备份或分享传给浏览器。

自动测试与类型检查：

```sh
node --test tests/*.test.mjs app/manage/filter-apps.test.mjs
npx tsc --noEmit
```

示例、管理、设置、指定项目创建、分享和候选 HTTP Smoke 均可对本地服务验收，具体命令见本地运行文档。自动测试使用 SQLite 与模拟模型响应，不替代浏览器交互或真实模型验收。

## 数据与安全边界

使用 React、Vinext/Vite、Cloudflare Worker 与 D1。匿名 HttpOnly Cookie 决定归属；测试资料不是正式账号，没有身份找回或跨设备同步。清除 Cookie 后不能恢复原匿名身份。项目原名 Forma，保留旧地址和存储标识以兼容历史作品。

保存与还原的是代码、需求和版本，预览中的输入、费用、计数或计时状态默认不持久化。HTML 导出独立运行后不再具有工作台 iframe 的隔离边界。JSON 备份包含需求与完整代码，应妥善保存；公开分享前须自行检查所选版本内容。

预览使用无同源权限的 sandbox="allow-scripts allow-forms"。JavaScript 表单事件可运行，CSP form-action 'none' 禁止实际表单提交；同时限制外部网络、资源和嵌套框架，宿主页面使用 frame-src 'self'。当前支持自包含单文件应用，不支持任意外部 API、依赖安装、多文件工程或生成应用获取服务端密钥。

模型调用最长三分钟，输出有完整性及长度检查，业务正确性仍需实际操作。每应用最多 60 个版本、每访客最多 100 个应用；每空间 50 个项目/50 个标签，每应用 10 个标签。每日按 UTC 计额：每访客 AI 10 次、示例 100 次，全站 AI 50 次、示例 2000 次；已接受的失败生成也占额度，两方案占两份。备份与候选另有限额，见对应文档。容量、滥用防护和长期生产可用性尚未完成验证。

通过 Sites 的受保护流程部署，生产迁移随发布应用。本地数据库、真实密钥和交付包不进入仓库；构建成功不代表已经上线。每次发布后均需核对实际地址、配置、旧数据及本批核心流程。
