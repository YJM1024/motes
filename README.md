# Motes Lite · 微粒轻量版

Motes Lite 是面向游客共享空间的轻量网页应用工作台。新应用默认使用 React 19 与 Tailwind CSS 4；已有单文件 HTML 应用继续沿用原有预览、修改与导出路径。你可以在隔离预览中操作应用、保存代码版本、恢复历史版本，并按需发布公开链接。

打开[线上 Lite](https://motes-yangjunmin.yjm1024.chatgpt.site/)体验。Lite 保留游客共享空间中的项目、应用、对话与应用显式保存的 SDK 业务数据；所有访问者都能看到并修改这些共享内容，请勿放入个人或机密信息。完整产品仍在[full-product 分支](https://github.com/YJM1024/motes/tree/full-product)。

## 三分钟体验

1. 打开线上 Lite，选择或新建一个应用。
2. 描述想制作的页面，等待规划和执行完成；没有模型配置时，可选择有明确标识的本地示例。
3. 在右侧隔离预览中操作页面，再描述要修改的内容。
4. 展开源码面板查看工程文件。面板只读；后续模型修改仅针对 `src/App.jsx` 与 `src/index.css`。
5. 打开版本历史查看或恢复代码版本，或发布当前版本并复制公开链接。

模型模式由现有两次调用构成：一次生成简短计划，一次生成新应用或修改。界面显示规划与执行阶段，不提供代码流式输出，也不把检查标成独立模型调用。检查失败时保留现有保存版本。

## 现有能力与实现边界

- 新应用采用固定 React 19 + Tailwind CSS 4 scaffold；Tailwind CSS 在服务端从静态完整类名编译，不依赖 CDN。固定工程使用独立构建工具链，不改变宿主构建器。
- 源码面板查看 7 个工程文件且只读。模型只可改 `src/App.jsx` 和 `src/index.css`；固定入口与依赖由工作台维护。
- 生成源码在编译阶段不会被执行；预览运行在带脚本和表单权限的隔离 iframe 中。HTML 应用继续走原有完整 HTML 检查和隔离预览路径。
- 工作台预览与公开页面可通过 Motes SDK 显式读写共享业务数据。恢复代码版本只切换代码，不回滚业务数据。独立 HTML 导出没有宿主 SDK 桥，SDK 数据仅能临时使用，并会显示不持久化提示。
- 当前 React scaffold 不支持任意 npm 依赖、容器或 ZIP 项目包；当前 Lite 不提供登录/auth 与代码流式输出。Lite 依赖网络，离线工作台保留在[完整版](https://github.com/YJM1024/motes/tree/full-product)。
